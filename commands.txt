git clone <url> — создаёт локальную копию удалённого репозитория по указанному url-адресу.
При этом скачивается вся история коммитов и ветки
git init — инициализирует новый локальный репозиторий в текущей папке.
git status — показывает текущее состояние проекта.
git push — отправляет локальные изменения в удалённый репозиторий.
git add — будут добавлены все отслеживаемые файлы в индекс для следующего коммита.
git log — выводит список всех коммитов, обычно в обратном хронологическом порядке.
